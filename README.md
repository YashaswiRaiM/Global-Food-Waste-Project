# Global-Food-Waste-Project
Global Food Waste Analysis &amp; Forecasting

## 📊 Project Overview
This project analyzes **global food waste** data to uncover trends, top contributing countries and food types, and economic losses. It also includes a **forecasting model** to predict future waste trends.  

The project uses **Python (pandas, matplotlib, scikit-learn)** for data cleaning, EDA, and forecasting, and **Power BI** for interactive dashboards.

---

## 🗂️ Repository Structure

Place your files in the folders:

data/cleaned/global_food_waste_clean.csv

data/raw/global_food_wastage_dataset.csv

report/powerbi_reports.pbix

README.md

## 🛠️ Tools & Technologies
- **Python**: pandas, matplotlib, seaborn, scikit-learn  
- **Power BI Desktop**: Interactive dashboards (Maps, Line charts, Column charts, Cards, Slicers)  
- **Data Visualization**: Trend analysis, top food categories, country-wise waste, KPI metrics  
- **Forecasting**: Linear Regression for predicting future waste trends  

---

## 🔹 Key Features
- **Data Cleaning**: Handle missing values, correct column names, convert data types.  
- **Exploratory Data Analysis (EDA)**: Identify trends by year, country, and food category.  
- **Forecasting**: Linear Regression to predict global food waste.  
- **Interactive Power BI Dashboard**:  
  - World Map of food waste  
  - Line chart for trend over years  
  - Column chart for top food categories  
  - KPI Cards for total waste, economic loss, and average per capita waste  
  - Slicers for `year`, `country`, and `food_category`

## 📈 How to Use
1. **Python Notebook**
   - Open `notebook/global_food_waste_analysis.ipynb` and run all cells step by step.  
   - Covers **data cleaning → EDA → Forecasting** in one workflow.  

2. **Dashboard (Power BI)**
   - Open `report/Global_Food_Waste_Report.pdf` for a static view.  
   - Or open the original `.pbix` file (if included) in Power BI Desktop for interactive visuals.
